A scatter plot squeezed into 360px is unreadable and untappable, so the small screen gets a different form carrying the same two variables.

Mobile · 340 × 560

How it keeps both axes

  • Information becomes the scroll direction. Sections run top to bottom, least dense to most — the one axis a tall narrow screen has real room for.
  • Fun becomes horizontal offset. Each dot sits further right the more playful its section, and the dotted line still traces the same path, so the shape survives the translation.
  • Labels anchor left at a fixed position rather than floating beside each dot, so nothing collides and nothing clips at the screen edge.
  • Each row is a full-width tap target, comfortably past the 44px minimum, instead of a 12px dot.

Accessibility

The handoff doc asks for real labels and no hover-only tooltips. Concretely:

  • Every dot is a real link with a full accessible name, not a shape with a tooltip. The visible text label is aria-hidden, so a screen reader announces the complete label once rather than stuttering the section name twice.
  • Nothing is hover-only. The readout below the graph is a convenience for sighted review; the position is already stated in each link’s accessible name, so keyboard and screen-reader users lose nothing.
  • Tab order follows the line, low information to high, so the sequence matches the visual path instead of SVG source order.
  • Focus is visible as a dashed ring plus a label colour change. Tab into the graph above to check it.
  • The graph is never the only route. Standard header navigation reaches every section, so a reader who cannot use the graph is never stranded.
  • Motion respects prefers-reduced-motion, and the dot transitions are decorative regardless.

Decisions taken

Settled during review. The graph above now shows what is actually built, not a proposal.

1. The connector line stays

It turns seven scattered dots into one legible descending path, and makes the trade-off — more information, less fun — the picture’s argument rather than a coincidence.

2. About moved from 76 to 34

It was never going to be that dense: one page against an archive of hundreds of posts. Events, Video, Audio and Blog shifted a few points each to absorb the change, so the line still reads as a single descending path with one deliberate spike at Video — the most purely entertaining format on the site.

3. Audio and Video stay adjacent

At 46/70 and 58/58 they sit close because they genuinely are similar in character. Prising them apart would have meant decorating the axes rather than using them. They remain two separate dots and two separate destinations — near each other, not merged.
